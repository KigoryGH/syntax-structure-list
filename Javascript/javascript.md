You use `console.log()` to log stuff to the console it's basically the `print()` function but for javascript.

Number, String, Boolean, Undefined and Null. Now the rest are not really used but it's good to understand which are: Bigint, Object and Symbol

Variables: there are actually 3 ways to declare a variable.

| functions to Decalare a variable                                           |
| -------------------------------------------------------------------------- |
| `var` _it's the old way to declare a variable_                             |
| `const` *you can declare a constant variable                               |
| that never changes to protect you're self from you're own stupidity*       |
| `let` _you can declare a variable that "let's" you change it unlike const_ |

note: *you'll never use the var function because it's old and outdated but you'll be using const and let and specially const because things can get messy in codebases, now if you need to change the variable use the let function*
