# Contribution 
so if you want to contribute you'll need to follow these rules:
**1-** this is not a beginners documentation, this made for people that are experienced with other programming languages and need some quick documentation just to get familiar with another coding language and start working with it.
**2-** when making a documentation for a language you have to create a folder/directory with the Name of the language and inside that folder you can have any assets related to that language's documentation and a markdown file which will be the heart of the documentation. for example `/Rust/rust.md`.
**🔴THE DOCUMENTATION FILE HAS TO BE IN MARKDOWN FORMAT ONLY TO KEEP CONSISTENCY BETWEEN ALL LANGUAGES🔴**
**3-** only 2 people can work on the same markdown file to keep consistency (this rule is flexible).
