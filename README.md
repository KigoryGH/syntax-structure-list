## Contributing

If you want to contribute, please follow these rules:

1. **This is not beginner documentation.** It's made for people who are already experienced with other programming languages and want quick documentation to get familiar with a new one and start working with it.

2. **Each language gets its own folder.** Create a folder named after the language, and put a markdown file inside it that will be the heart of the documentation, for example `Rust/rust.md`. The folder can also hold any assets that language's documentation uses.

   > [!IMPORTANT]
   > The documentation file has to be in Markdown format only, to keep consistency between all languages.

3. **Keep a file to one or two main contributors.** This keeps the style of each language's documentation consistent. This rule is flexible.
